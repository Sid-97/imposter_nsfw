# The Imposter Game

A mobile-first, pass-the-phone party game for 3–10 players. It is built with plain HTML, CSS, and JavaScript and can be hosted directly on GitHub Pages.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select the main branch and the root (`/`) folder, then save.
